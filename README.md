# Flash To-Do Web Application

A full-stack, responsive To-Do application built with a **Python Flask REST API** backend and an **HTML/JavaScript** frontend styled with **Bootstrap 5**.

## 🚀 Features
* **Create:** Add new tasks dynamically with status feedback alerts.
* **Read:** Fetch and display all active tasks from the Flask backend.
* **Update:** Toggle task completion status with a single click (strikethrough styling).
* **Delete:** Remove tasks in real-time.
* **Responsive Design:** Styled using Bootstrap 5 to look great on desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, JavaScript (Async/Await Fetch API), Bootstrap 5
* **Backend:** Python, Flask, Flask-CORS

---
